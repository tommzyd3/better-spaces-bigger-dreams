## Kako ogledati

Odpri `index.html` v brskalniku ali omogoči **GitHub Pages**.

### GitHub Pages

1. Pojdi v **Settings → Pages**
2. Source: Deploy from a branch → `main` / root
3. Shrani

Stran bo na: `https://tommzyd3.github.io/better-spaces-bigger-dreams/`
